# MusicXML → 简谱

把 MusicXML 转成简谱，交付**一个独立的 HTML 网页**：乐谱已经内嵌，用户打开就能看。转换和排版全部由页面里的脚本在浏览器本地完成（不上传任何服务器），所以本技能不需要在沙箱里渲染乐谱，只负责校验输入、生成页面、把结果交给用户。

## 工作流程

1. **找到乐谱文件**：用户上传或指定的文件（在 Claude.ai 里通常是 `/mnt/user-data/uploads/`，其他环境按用户给的路径）。支持 `.mxl`（压缩）、`.musicxml`、`.xml`。
2. **运行构建脚本**（只用标准库，不用安装任何东西）：
   ```bash
   python3 scripts/build_jianpu.py <乐谱文件> -o <输出目录>
   ```
   输出目录：Claude.ai 里用 `/mnt/user-data/outputs/`（用户才能拿到文件），其他环境用当前目录即可。
   - 用户只要某几个声部（例如"给二胡做一份分谱"）时加 `--parts "二胡"`。名称按"包含"匹配，多个用逗号分隔，也可以写声部 id（如 `P16`）。这只是**预选**，页面里仍可以勾选其他声部。
   - 只想先看乐谱里有什么：加 `--summary-only`。
3. **读脚本打印的摘要，向用户简短说明**：曲名、声部数和小节数、调与拍号、有没有变调/变拍/反复，以及摘要里"提醒"部分的内容（例如某些声部整首休止）。不要把摘要原样贴给用户，挑他们关心的说。
4. **交付**：把生成的 `.html` 文件交给用户（Claude.ai 里用 `present_files`；其他环境告诉用户文件路径），然后用几句话说明用法（见下节）。
5. **脚本报错时**：错误信息本身就是写给用户的话（例如"这是 PDF""这是 MuseScore 原生格式"），照实转述并告诉用户下一步怎么做，不要自己编一个变通办法硬转。

## 告诉用户怎么用生成的网页

- 页面上方勾选要显示的声部；「调号」下拉框可以改调；「字号」调大小。
- **要给某个团员发分谱**：只勾他的声部，点「下载谱面」，得到一个独立的网页文件，双击打开后按 ⌘P（Windows 为 Ctrl+P）即可打印或存为 PDF。
- 用户要 PDF：本技能不在沙箱里生成 PDF（那里通常没有浏览器）。让用户按上面的方式从浏览器另存为 PDF。
- **优先交付文件，而不是发布成网页链接**：网页被嵌入或托管时，浏览器常会拦截「下载谱面」和「打印」，而分发分谱恰恰需要这两个功能。

## 输入不是 MusicXML 时

脚本会自动识别并给出提示，你只需转述：

| 输入 | 处理 |
|---|---|
| PDF / 图片 | 不能直接转。需要先用乐谱识别（OMR）软件（如 Audiveris）转成 MusicXML，识别结果通常要人工校对。如果乐谱原本是打谱软件做的，直接导出 MusicXML 更准确 |
| MuseScore 原生格式 `.mscz` | 在 MuseScore 里「文件 → 导出 → MusicXML」 |
| MIDI | 没有完整的记谱信息，转出来不可靠；建议先在打谱软件里整理，再导出 MusicXML |
| timewise 格式的 MusicXML | 重新导出为常规的 partwise 格式（多数软件默认就是） |

## 转换规则（用户问"这个符号是什么意思"时用）

- **首调唱名**：1 = 谱面调号的主音。小调曲目按关系大调记谱（国内简谱通行做法）。可以在页面里用「调号」下拉框改写。
- **音高**：数字 1–7；高八度在数字上方加点，低八度在下方加点；升降号写在数字前。
- **时值**：八分及更短的音符用数字下方的横线；四分音符不加线；延长用"—"；支持附点。
- **休止**：写作 0。休止符一律不使用延时线（二分休止记作 0 0），空白小节统一记作 0 0。
- **其他记谱**：连音线/圆滑线、三连音（标数字）、倚音、反复记号和房子、变调和变拍处的标记、歌词（显示在音符下方）。
- **按声部名称自动识别乐器**：弹拨乐（琵琶、柳琴、阮、扬琴、古筝等）的倚音改记为音符上方三道横线（轮/滚奏）；笛类的倚音改记为 tr（颤音）。
- **打击乐**：无音高音符记作 ×。
  - 鼓类：鼓心记作带圈的 ⊗，鼓边记作普通 ×。
  - 木鱼：高音在 × 上加点，低音在 × 下加点；高低同时敲击则上下各加一点。
  - 每个打击乐声部下方会标出图例。哪个音色算鼓心/鼓边、高/低，页面按乐器名称（High/Low、rim 等）和使用频率自动判断，判断不对时用页面里的「打击乐记号」一行手动改。
- **分段与小节号**：双纵线、终止线、分页处或带编号的标题文字（如"三、""2.""III."）会自动分乐章，所有声部分段一致；每 5 小节在左上角标小节号。
- **速度类标记**（rit.、渐慢、节拍器记号等）出现在每个声部；pizz.、滑奏这类乐器专属标记只保留在对应声部。

## 已知局限

如实告诉用户，不要暗示更多功能：

- **不显示的记号**：力度（p、f 等）、渐强渐弱、重音、断奏、延长记号（fermata）、波音和回音等装饰音。装饰音里只处理颤音（tr）、波浪线和轮奏（音符上方的三道横线）。
- 同一声部里的多个 voice（例如双谱表乐器）按 voice 各占一行。
- 只支持 partwise 格式的 MusicXML；不做乐谱识别。
- 需要较新的浏览器（读取 `.mxl` 压缩包用到浏览器内置的解压功能）。
- 性能：一份 18 声部、169 小节的总谱，在 Chrome 中约 1 秒内渲染完；更大的乐谱没有测试过。

## 修改这个技能

- 转换和排版逻辑都在 `assets/jianpu-template.html`：单个文件，无任何外部依赖，直接双击就是一个空白的转换器（用户可以自己拖入乐谱）。
- 页面在 `<!--EMBEDDED_SCORE-->` 处接收构建脚本嵌入的乐谱；改模板时保留这个占位符和文件末尾的"embedded score"那段脚本即可。
- 改完可以用示例乐谱和 `evals/evals.json` 里的提示词自测。
